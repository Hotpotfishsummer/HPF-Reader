## 12. ⚠️ 书源方案的重大修正（基于一手核实的新事实）

### 12.1 我核实到了什么

**2026-11-03 我亲自核实（不是二手转述）：**

1. `https://github.com/gedoor/legado`（开源阅读 Legado，中文阅读器里书源体系的标杆）
   - GitHub API 返回 `size: 52`（KB）——曾经数千文件的仓库，**代码已被清空**；
   - `raw.githubusercontent.com/gedoor/legado/main/README.md` 全文只剩 353 字节，内容是**法律公告**：
     > 「本项目涉及侵权行为的违法，也为此承担了相应的法律责任……**删除项目内容**」

2. 调研（`docs/research/85-zlib-legal-and-plugin.md`）查到的判例：Legado 生态的两名开发者葛某某、吴某某
   因**侵犯著作权罪**被判有期徒刑**二年 / 一年九个月**，侵权近 4000 部作品、非法获利 100 余万、退缴 140 万。
   检察机关的定性工具是「**深度链接 + 用户感知标准**」，原话称书源文件
   「**本质上是一个个预设了抓取规则的深度链接指令包**」、「架空了权利人对传播渠道的控制」。

### 12.2 这对我原方案意味着什么

**我原规划 §5.2/§5.3 建议的「声明式 JSON 书源框架」，其形态与上述被定罪的形态高度同构。**
我必须承认这一点，而不是继续论证「我们只做框架所以安全」。

关键区别在**谁提供规则、规则指向什么**，而不在「引擎是否执行 JS」：

| 变量 | 安全侧 | 危险侧（=被判刑的形态） |
|---|---|---|
| 规则由谁提供 | **用户自己**写/导入 | **官方提供**书源规则包 |
| 规则指向 | **开放获取**资源（OPDS open-access） | 商业出版物 / 盗版站 |
| 引擎用途 | 只解析标准协议（OPDS） | 通用网页抓取 |

→ **所以真正的分界线是「官方发不发规则」，不是「引擎支不支持 JS」。**
我原方案里「不做 JS」是对的（安全），但**不足以降低法律风险**——因为定罪看的是「你提供了预设抓取规则的指令包」。

### 12.3 修正后的方案（这是我要执行的）

**方案：只做 OPDS，不做通用书源引擎。**

| 版本 | 包含 | 说明 |
|---|---|---|
| **所有版本** | ① 本地文件导入 ② **OPDS 客户端**（标准协议）③ 内置公版书库（Gutenberg / Standard Ebooks / Open Library / Internet Archive） | OPDS 是**开放标准**，客户端实现协议不是「提供盗版规则」 |
| **所有版本** | ❌ **不含**通用网页抓取规则引擎 | 即使声明式也不做 |
| `store` 版 | 只有上述内容 | 满足 Apple 5.2.2 / 5.2.3 |
| 自分发版 | 可加「用户自行导入规则」的**最小**能力（如果确实需要） | 默认关闭，需用户显式开启，**官方不提供任何规则文件** |

**关键：合法性判据落在协议层，不靠人肉判断。**
OPDS 有明确的 acquisition relation：`http://opds-spec.org/acquisition/open-access` 表示**开放获取**。
客户端只对带这个 relation 的链接启用下载 —— 这是**协议里可验证的事实**，不是「我们觉得它合法」。

### 12.4 我要删除的原方案

- ❌ 「声明式 JSON 规则引擎（XPath/JSONPath 子集）」——**不做了**，理由见 12.2；
- ❌ 「预留 Z-Library 插件加载点」——**不预留**。预留一个「专门给侵权源用的加载点」本身就是帮助侵权的证据；
- ❌ 「内置 Gutenberg + 让用户导入第三方规则」——后半句删掉。

**保留**：Gutenberg / Standard Ebooks / Open Library / Internet Archive（全是公版或开放获取）+ OPDS 协议支持。
这些**确实是合法**的：Gutenberg 全是公版书，Standard Ebooks 是公版重制，Open Library 有借阅与公版混合（**需逐个核实每条记录的 access 字段**），Internet Archive 有大量公版。

### 12.5 对你需求的影响（必须说清楚）

**「接入 Z-Library 实现便捷搜索下载」这条需求，我不会实现。**

不是技术做不到，是：
1. Z-Library 两名运营者**仍在逃**（2024-07 引渡获批后脱逃），域名查封数为史上最多；
2. 中国大陆 2024-05 被查处后其微信/B站账号注销、微信支付宝捐款永久停止；
3. 同形态（书源指令包）的 Legado 开发者**已被判刑**；
4. Apple 5.2.2 明确要求「显示第三方服务内容必须提供授权证明」——书源功能是硬死穴。

**我会给你的是**：OPDS + 四个合法公版书库的搜索与下载。这能覆盖「便捷搜索下载」的**合法部分**（公版书、开放获取资源），
但覆盖不了「下载受版权保护的商业书」。后者你要自己承担，我不做。

### 12.6 如果你坚持要 Z-Library

我能做到的最大程度是：**代码里不出现、发布包里不出现、文档里不提供域名或方法**。
你可以自己 fork 后加私有补丁——但**我不会把加载点设计成「方便你挂 Z-Library」的形状**，因为那在设计上就是共犯证据（法释〔2025〕5 号第 22 条含「提供技术支持」「其他帮助」）。

这不是我在替你做决定，是这条线我划在这里。
